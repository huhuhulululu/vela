# Vela

面向 Chaturbate 的 macOS 原生播放器。窗口可以浮在所有桌面之上，指针离开时变淡并让出点击；直播用 AVPlayer 硬件解码，不内嵌浏览器播放。

## 使用

用 Xcode 15 或更新版本打开 `Vela.xcodeproj`，目标系统是 macOS 14。直接运行即可。

- 滚轮、↑ ↓ 或 J / K 切换房间；按住左键拖动画面或顶栏空白处可移动窗口（画面上按下后移动几个点才开始拖，单击按钮不受影响；顶部提示横幅只有本体可点，不会挡住控制栏，两条横幅不会同时出现）。下一个地址会提前解析；切房时在画面就绪前用该房间缩略图的模糊版垫底（并预取下一间缩略图），就绪后视频约 0.3 秒淡入，避免整屏纯黑。
- ⇧⌘P 置顶，⇧⌘T 开关离开后淡出。淡出程度、点击穿透和「离开后降低画质」在半圆按钮里：指针离开约 10 秒后当前房间换低画质，回来换回。
- 空格暂停 / 继续，M 静音 / 取消静音（首次打开默认静音；音量拉到 0 后取消静音会回到 20%），F 切换铺满或完整画面；竖屏直播出画面后当前房间自动用完整画面（不裁切），离开该房间恢复你的铺满设置，在竖屏房间里按 F 只撤掉这一次的自动，不改你的设置。这些单键在弹层（筛选、收藏夹、口味、确认页）打开或正在输入时不触发，字符留给输入框；搜索框里打字只过滤列表、不换当前房间，回车才换房并起播。音量在顶栏喇叭图标里。房间信息（名字、标签、推荐理由）只在控制栏显示时出现，控制栏收起时一起淡出；I 键或「播放」菜单可切换为「始终显示房间信息」。窗口被遮挡或最小化时自动暂停。
- ⌃⌥⌘V 老板键（全局，不需要辅助功能权限）：隐藏窗口并停止解码，再按一次恢复显示并继续播放。锁屏、屏幕睡眠、切换用户时自动暂停，回来后恢复；手动暂停的会保持暂停。
- 常看的主播会温和提示是否收藏（累计实际观看满 10 分钟，或看过 3 次且每次至少 1 分钟、间隔 30 分钟）；不自动收藏，每位主播只提示一次（点了「收藏」或关闭才算问过，提示自己超时消失不算，之后还会再提示；点击穿透期间不显示，指针回到窗口再显示），暂停学习时不累计。记录在 `watch-ledger.json`，清除全部偏好数据时一并删除。
- 收藏夹：顶栏心形图标，左键收藏 / 取消收藏当前房间（画面上方提示一下），右键打开收藏夹；⌘D 同样收藏 / 取消收藏，⇧⌘F 打开收藏夹，⇧⌘B 屏蔽。收藏夹里在线的收藏排在前面，带缩略图、人数与开播时长，整行点击直接切过去；其余（离线、当前地区不可观看、未查询、不存在）弱化显示；离线的显示上次开播时间（如「上次开播 3 小时前」），按最近开播排在前面。上次开播时间只在打开收藏夹时为离线的收藏按需查询（并发 4，缓存 30 分钟），不在后台轮询。行尾有弱化的「移除」按钮（悬停加强，右键菜单也能移除；底部可撤销），离线行的状态文字始终保留；可以按用户名手动添加（回车），在「更多」里导出、导入 JSON 文件（导入时去重合并）；屏蔽名单是弹窗里的二级页。屏蔽的房间在所有来源里都不再出现，当前房间被屏蔽会立即切到下一个；收藏的房间在猜你喜欢里加权。名单存在 Application Support 的 `feed-curation.json`，各最多 300 个。
- 菜单栏图标（帆船）：应用运行时常驻，点开列出在线的收藏（缩略图、人数与开播时长，排序与收藏夹相同），点一行把窗口带到前面（老板键隐藏时也恢复）并切到该房间；顶部一行摘要，底部「刷新状态」和「打开收藏夹」。打开菜单时若状态缓存过期会补查一次，菜单关着时不发请求。「播放」菜单里的「在菜单栏显示」可以关掉图标（默认开）。
- 房间目录用站点自己的公开列表接口，不带任何联盟 / 推广参数，所以浏览不会记到任何第三方推广账号下。筛选面板有搜索框、性别、地区、标签和「仅公开」；标签输入下方列出全站热门标签，点一下即按它筛选（热门标签缓存 6 小时，取不到时用在线房间的常见标签）。搜索框打字时只在已加载的房间里过滤，不发请求，也不换当前房间；按回车时本地有匹配就换到该房间，本地没有匹配再查全站（一页，站点自己的搜索），结果作为临时列表浏览，清空搜索框回到原来的来源；全站也没有结果时，输入的是合法用户名就照旧直达该房间。原来的「仅高清」和「联盟 ID」已移除（站点列表接口没有高清字段，联盟 ID 也不再使用）。旧版存下的这两项设置读取时直接忽略。
- 不需要账号，也不登录站点；站点要求确认访问（含年龄确认页）时会弹出网页让你确认一次（只有页面确实是确认页才弹；普通的 403 / 503 当作暂时无法播放并自动跳过；连续被拦时最多弹两次，之后改为提示并跳过；弹出确认页时会先停掉当前画面）。快速连划时只保留最后一次起播，前面未完成的解析会被取消。断网时请求立刻失败并显示「网络不通」，可以重试。站点返回的不是正常数据（限流页之类）时按暂时不可用处理，同一接口 30 秒内不再重发。
- 起播时先用一次房间状态请求同时拿到状态与播放地址，拿不到再用原来的流地址接口；公开却拿不到地址时提示「当前地区不可观看」，不当成离线。
- 主播暂时离开时不自动跳走：停在房间提示「暂时离开，稍后自动重试」，停留 60 秒后再查一次；仍离开就保持提示，由你决定重试或换房。换房或暂停会取消这次重试。
- 顶部可切四种来源：猜你喜欢（默认）、热门（接口原顺序）、新开播（用站点自己的新开播筛选，可与性别、地区、标签叠加，开播时间从短到长）、收藏。选择会记住。收藏来源只列出当前在线、可播放的收藏房间（人多的在前）：先用已加载的目录与 3 分钟内的缓存比对，没有答案的才逐个向站点查询（并发 4），切到收藏或点「重试」「刷新状态」时才查，不在后台轮询。
- 猜你喜欢只在本机计算，按标签与性别做汤普森采样：每个标签有自己的命中与落空记录（在房间里看满 20 秒算命中，3 秒内划走算落空，之间不计），排序时各标签按记录抽样，对味的标签排前面，没试过的标签也有机会冒头，所以不需要另加随机位。热度只在口味相近时分先后，最近看过的靠后，收藏的加分，标成「不想看」的标签直接过滤。记录按 7 天半衰期衰减，旧口味不会永久占着。停留越久学得越多（3 秒内划走只算弱落空，快速浏览不会把口味压垮），几乎每个房间都有的泛标签（如 teen、18）影响很小；常看的主播会稍微靠前（不超过收藏），也会按你最喜欢的几个标签额外拉一些房间进来。每个房间的信息块里有一行推荐理由（因为你常看 xx、你收藏的主播、试试新口味）。
- 我的口味：顶栏闪光图标。看每个标签的强弱与命中次数，一键加强、不想看或移除；查看最近 7 天命中率；画像还空时先从全站热门标签里点选整理（取不到时用在线房间的常见标签）；可暂停学习、重置画像、清除全部偏好数据（都要二次确认；清除口味与观看记录，收藏与屏蔽保留）。「播放」菜单里的「对当前房间不感兴趣」（⇧⌘N）记一次强落空并立即切到下一个。画像存在 Application Support 的 `feed-taste.json`（标签最多 500 个、单个标签 / 用户名 64 字符、文件 1MB 都有上限，超过 1MB 按空画像处理），只保存在这台 Mac 上，不上传任何数据；旧版的偏好文件会在首次启动时折算迁移。


首次打开需要确认已满 18 岁。第一次进入播放会有三行可关闭的提示（拖动画面移动窗口，滚轮或 ↑↓、J / K 换房间，右键心形打开收藏夹）。「播放」菜单里有「重试当前房间」；列表为空时按原因说明（全被屏蔽、全被不想看过滤、没有公开房间、目录失败、收藏都不在线、确实为空）。复查后仍没有可听音轨的房间会提示「这路没有声音」。

## 应用图标

图标源文件是 `design/icon/vela_icons.swift`（CoreGraphics 绘制），改动后在仓库根目录重新生成全部尺寸：

```sh
swift design/icon/vela_icons.swift App/Assets.xcassets/AppIcon.appiconset
```

## 性能测量

`scripts/perf-probe.sh` 在本机后台静音播放一段时间，采样 CPU、内存、唤醒、网络与请求数，输出一行 JSON；`--scenario idle` 测停播后的空闲开销。运行期间会临时改写 `com.vela.stage` 的年龄确认与静音设置，结束后恢复。用法、基线与各轮优化实测见 `docs/PERF.md`。

## 逻辑测试

核心目录、播放地址、切房和透明度不依赖 AppKit，在仓库根目录执行：

```sh
swift test
```

## 安卓

安卓版是 `android/` 下的独立 Gradle 工程，不编译 macOS / iOS 的 Swift。`:core` 是纯 JVM 逻辑，`:app` 用 Jetpack Compose 画界面、用 Media3 ExoPlayer 播放，不另开本地中继端口。当前是竖屏单窗，并已接上竖屏双窗（第三格只留界面槽位，不创建播放器）与画中画（回桌面只留焦点路，3 秒内未进入则全停）：四个来源、上下滑切房、收藏与口味、默认静音、首次打开确认已满 18 岁；站点要求确认访问时在 WebView 里完成。只装自己的手机，不上架。

在 `android/` 目录构建并跑单元测试：

```sh
./gradlew :core:test :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease
python3 -I tools/parity.py --all
```

结构见 `docs/ARCHITECTURE.md` 第 11 节，测量口径见 `docs/PERF.md` 的安卓一节，移植约定见 `android/PORTING.md`。
